# Bundle Ekspor Hasil Audit

Folder ini adalah bundle ekspor read-only. Jangan edit salinan di sini; edit sumber kanonik di `docs/`, lalu sinkronkan kembali.

Struktur kanonik saat ini:

- `docs/agent-rules/` untuk aturan coding agent dan runtime LLM;
- `docs/architecture/` untuk kontrak dan desain;
- `docs/runbooks/` untuk prosedur operasional;
- `docs/audits/` untuk audit/evidence historis;
- `docs/reports/` untuk report fase dan maintenance.

Lokasi lama `docs/cursor-ai/` dan `docs/instructions/` tidak lagi digunakan.
